二、基本结构

语句通常以句号（。）结尾，可省略；冒号（：）用于定义；代码块通过缩进区分（子语句缩进必须大于父语句）。

变量名：值。 如果 条件： 说（“缩进大于父级即可”）。

注释

// 单行注释 /* 多行 注释 */

同一行多条语句

a：1，b：2。 a：3，说（a）。

三、字面量与变量

类型示例说明
整数42普通整数
小数3.14浮点数
字符串“你好”中文引号括起，拼接用 +，换行 \n，引号内转义 \“
布尔正确 / 错误也可写 真/对、假/错
空值空等于 null

变量定义

数：42。 字符串：“你好”。 布尔：正确。 数 是 100。 // “是”也可作赋值号（成员赋值尤其好用）

把/设字句（赋值语法糖）

把 分 增加 5。 // 分 += 5 把 分 减少 2。 // 分 -= 2 设 分 为 100。 // 分 = 100 将 分 设为 50。 // 分 = 50 把 勇者之生命 减少 30。

"的"语缀

词尾的"的"是无实义语缀，不影响取值：正确的 等于 正确，空的 等于 空。高亮时语缀按标点灰显。

五、条件判断

如果（成绩 大于等于 90）： // 括号可省略 说（“优秀”）。 否则如果 成绩 大于等于 60， 说（“及格”）。 否则： 说（“不及格”）。

分支分隔符支持冒号（：）或行末逗号（，）；也支持行内写法与口语后缀"的话"：

如果 1 是 1：说（“一行搞定”），否则：说（“不会执行”）。 如果 天气 是 “雨” 的话： 说（“带伞”）。

选择（按值匹配）

选择（等级）： 情况 1， 说（“一级”）。 情况 2： 说（“二级”）。 否则： 说（“其他”）。

六、循环

重复（for）

重复（开始于i=0，到i小于5为止，每次i++）： 说（i）。

循环 N 次

循环 3 次（序号）： 说（序号）。

当…时（while）

当 运行 时： 走（）。

重复 直到…为止（do-while，至少执行一次，条件满足后停止）

重复 直到 分数 大于 100 为止： 分数：分数 + 1。

每当…就

每当 n 小于 3，就 把 n 增加 1。 每当 m 小于 3： // 也支持缩进块 m：m+1。

遍历（for-of）

遍历 名单 中 的 每个 元素： 说（元素）。

结束 相当于 break，跳出当前循环。

七、函数

问候：输入 名字； // 参数用顿号分隔 结果是 “你好，” + 名字。 说（问候（“小明”））。

默认参数

问候：输入 名字 缺省 为 “路人”； 结果是 “你好，” + 名字。

无参函数与"如下"函数头

当前时间：输入； 结果是 日期之now（）。 打招呼 如下： // 等价于 打招呼：输入； 说（“你好”）。

函数引用可作为参数传递（回调）：添加事件监听（“click”，处理）。

八、数组

蛇身：【210、209、208】。 // 【】包裹，顿号分隔 名单：1、2、3、4、5。 // 定义右侧可直接顿号列举 空表：【】。 矩阵：【1、2、3】、【4、5、6】。 // 嵌套用【】包裹

索引（1 基）

名单第1项。 名单第i项。 // 变量索引 名单第一项。 // 中文数字：第一项/第十项/第二十三项 名单之第3项。

中文数字须紧跟在"项"前（第一项），第一个子节点 仍是普通标识符。

列表标准库

列表之长度 / 追加 / 移除（1基） / 包含 / 连接 / 排序 / 反转 列表之映射 / 筛选 / 归并 // 回调函数 列表之查找（1基，找不到为 0）

九、文本（字符串）

文本之长度 / 拆分 / 替换 / 查找 / 包含 文本之转大写 / 转小写 / 修剪 / 子串 / 连接
说（文本之拆分（“a，b，c”，“，”））。 说（文本之替换（“你好世界”，“世界”，“苦瓜”））。 说（文本之连接（“春”，“夏”，“秋”））。

十、类与对象

勇者： 名字：“勇者”。 生命：100。 受伤：输入 伤害； 此之生命：此之生命 - 伤害。 // 此/本 = this 结果是 此之生命。

成员访问用 之 或 的：勇者之生命、勇者的生命；成员赋值 勇者之生命 是 90。；支持方法链 文档之创建元素（“div”）之设置文本（“你好”）。

十一、错误处理

尝试： 读取文件（“配置.json”）。 如果报错（错误信息）： // 假如报错 / 要是报错 亦可 说（“读取失败：” + 错误信息）。

也支持行内写法：尝试：读取文件（“a”），如果报错：说（“失败”）。 错误变量可省略。

十二、模块与异步

引入 “node:path” 作为 路径模块。 // 或 称作 引入 “os” 称作 系统模块。 说（路径模块之join（“a”，“b”））。 导出 变量 作为 别名。 // CommonJS module.exports 等待 定时器之setTimeout（1000）。 // await：函数内自动 async，顶层异步运行

引入 编译为 require，在 Node.js 与 Vite/esbuild 打包工具中可用；浏览器运行时暂不支持。
