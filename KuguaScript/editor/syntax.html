苦瓜脚本语言 语法规则

一、基本结构

苦瓜脚本语言使用全角中文标点作为语句分隔符，句号（。）结束一条语句，冒号（：）用于定义，分号（；）用于函数定义后。

变量名：值。
每条语句必须以句号（。）结尾。函数定义以分号（；）结尾后接函数体。

二、变量定义

使用冒号（：）进行变量定义和赋值。

数：42。 字符串：“你好”。 小数：3.14。

数据类型

类型示例说明
整数42普通整数
小数3.14浮点数
字符串“你好”用中文引号括起
布尔值正确 / 错误也可用：真/假、对/错
空值空等同于 null

三、输出

使用说关键字输出内容，等同于 console.log。

说（“你好，世界！”）。 说（42）。 说（变量）。

算术运算

运算符号示例
加法+1 + 2
减法-10 - 3
乘法*4 * 5
除法/20 / 4

逻辑运算

五、条件语句

使用如果、否则如果、否则进行条件判断。条件用括号（）括起，冒号（：）结尾。

如果（成绩 大于等于 90）： 说（“优秀”）。 否则如果（成绩 大于等于 60）： 说（“及格”）。 否则： 说（“不及格”）。
代码块通过缩进区分，子语句的缩进必须大于父语句。

六、循环语句

重复循环（for 循环）

使用重复关键字，语法：重复（开始于 变量=初值，到 条件 为止，每次 变量++）：

重复（开始于i=0，到i小于5为止，每次i++）： 说（i）。

循环次数（repeat-n）

使用循环关键字，语法：循环 N 次（变量）：

循环 3 次（i）： 说（i）。

七、函数定义

使用输入关键字声明参数，参数名用中文引号括起，多个参数用顿号（、）分隔。函数体以分号（；）开始。结果是用于返回值。

问候函数：输入“名字”； 结果是“你好，” + 名字。 说（问候函数（“苦瓜”））。

八、类（对象）定义

类名后接冒号（：），内部通过缩进定义属性和方法。属性以句号（。）结尾，方法以分号（；）结尾。使用之访问成员。

计算器： 加法：输入“a”、“b”； 结果是a + b。 减法：输入“a”、“b”； 结果是a - b。 说（计算器之加法（3，5））。
类的方法内部暂不支持通过 this 访问类属性，方法只能使用自身参数和外部变量。

九、注释

支持单行注释和多行块注释，语法与 JavaScript 相同。

// 这是单行注释 /* 这是多行注释 可以跨越多行 */

十、标点符号速查

标点用途
。语句结束（相当于分号 ;）
：定义/赋值（相当于等号 =）
；函数头结束，接函数体
，参数分隔 / 逻辑或（OR）
、参数分隔 / 逻辑与（AND）
（）括号分组 / 函数调用
“”字符串引号
【】方括号字符串（等同引号）
