本项目是一个名为KuguaScript（苦瓜脚本语言）的纯中文脚本语言编译器项目，用于将KuguaScript脚本（.ks文件）编译为JavaScript脚本（.js）

## 语法说明

完整的语法规则见 [编辑器语法文档](editor/syntax.html)。

### 条件语句

- `如果` 后面的条件可以省略括号：`如果 成绩 大于等于 90：`
- 条件可以以逗号结尾进入分支：`如果 成绩 大于等于 90，`
- `否则：` 与 `否则，` 均可进入默认分支，`否则如果` 同样支持省略括号与逗号结尾
- `重复`、`循环`、`选择` 等语句的分支分隔符同样支持冒号或逗号
- 同一行内的逗号（，）仍表示逻辑或（OR）；行末逗号表示语句/分支分隔

### 快速开始

```bash
npm test                    # 运行测试
npm start                   # 启动编辑器服务器（http://localhost:3002）
node build-browser.js       # 重新生成浏览器端编译器（editor/kugua-compiler.js）
```
