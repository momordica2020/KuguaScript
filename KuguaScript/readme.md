# 苦瓜脚本（KuguaScript）

苦瓜脚本是一个**纯中文脚本语言**，把 JavaScript 编译为目标，覆盖 Node.js 与浏览器的全部应用场景。
语法以中文句式为基础：`如果…那么…`、`把 分 增加 1。`、`遍历 名单 中 的 每个 元素：`，
同时保留与 JS 生态互操作的能力（`引入` / `导出` / `等待`）。

## 特性一览

- **纯中文语法**：`如果/否则/选择/重复/当…时/每当…就`、把/设字句、`的`语缀、中文数字索引
- **标准库全中文接口**：`路径`、`网址`、`加密`、`文件`、`系统`、`环境变量`、`缓冲`、`服务器`、`画布`、`剪贴板`、`文本`、`列表`
- **Node / 浏览器双端**：CLI 运行与编译、浏览器加载器、Vite/esbuild 构建插件、VS Code 扩展
- **异步与错误处理**：`等待`（await）、`尝试…如果报错`
- **模块互操作**：`引入 “node:path” 作为 路径模块。`、`导出 变量 作为 别名。`

## 快速开始

```bash
node cli.js 脚本.ks               # 直接运行
node cli.js 脚本.ks --compile     # 只输出编译后的 JavaScript
node cli.js 脚本.ks -o 输出.js    # 编译并写入文件
node cli.js                       # 交互式运行环境（空行执行，输入"退出"结束）
```

示例：

```ks
// 你好，世界
说（“你好，世界！”）。

// 条件与循环
成绩：85。
如果 成绩 大于等于 90：
    说（“优秀”）。
否则如果 成绩 大于等于 60：
    说（“及格”）。
否则：
    说（“不及格”）。

重复（开始于i=0，到i小于5为止，每次i++）：
    说（i）。

// 数组与遍历
名单：【“甲”、“乙”、“丙”】。
遍历 名单 中 的 每个 元素：
    说（元素）。
```

## 语法速览

完整语法见 [语法指南](editor/syntax.html)（编辑器内"语法规则"页面）。

```ks
// 赋值句式
把 分 增加 5。          // 分 += 5
设 分 为 100。          // 分 = 100
勇者之生命 是 90。       // 成员赋值

// 成员判断
如果 “你” 在 名单 中：
    说（“在”）。

// 流水句（结果存入"它"）
先 文本之拆分（“a，b，c”，“，”），
再 列表之反转（它），
最后 说（它）。

// 错误处理
尝试：
    读取文件（“配置.json”）。
如果报错（错误信息）：
    说（“读取失败：” + 错误信息）。

// 异步与模块
引入 “timers/promises” 作为 定时器。
等待 定时器之setTimeout（1000）。
```

## 内置运行时

### 平铺动词（日常函数）

输入输出：`说`、`弹窗`、`询问`、`确认`、`读取输入`、`写入`
文件系统：`读取文件`、`写入文件`、`追加文件`、`删除文件`、`存在文件`、`读取目录`
其他：`随机数字`、`向下取整`、`向上取整`、`绝对值`、`转整数`、`转数字`、`解析JSON`、`字符串化JSON`、`设置定时器`、`设置循环`、`请求动画帧`、`获取`（fetch）

### 中文命名空间标准库

| 命名空间 | 典型方法 | 环境 |
|---|---|---|
| `路径` | 拼接、解析、目录名、文件名、扩展名、相对、绝对化、分隔符 | Node |
| `网址` | 解析（协议/主机/域名/端口/路径/参数） | Node |
| `加密` | 哈希、随机字节、随机标识 | Node |
| `文件` | 读取、写入、追加、删除、存在、列出、复制、移动 | Node |
| `系统` | 平台、架构、处理器数量、内存、主机名、临时目录、用户目录 | Node |
| `环境变量` | 读取、设置、删除、全部 | Node |
| `缓冲` | 从文本、转文本、从十六进制、转十六进制、长度、拼接 | Node |
| `服务器` | 创建、监听、关闭；请求之网址/方法/头/读取体，响应之状态/设置头/发送 | Node |
| `画布` | 创建；上下文之设置填充色/填充矩形/填充圆/填充文本/清空… | 浏览器 |
| `剪贴板` | 读取、写入（配合 等待） | 浏览器 |
| `文本` | 长度、拆分、替换、查找、包含、转大小写、修剪、子串、连接 | 两端 |
| `列表` | 长度、追加、移除、包含、连接、排序、反转、映射、筛选、归并、查找 | 两端 |
| `数学` | 平方根、乘方、正弦、余弦、正切、最小值、最大值、圆周率 | 两端 |
| `日期` | 现在、年、月、日、时、分、秒、格式化、时间戳 | 两端 |

## 网页端（浏览器）

编辑器与普通网页共用浏览器运行时。加载方式：

```html
<script src="editor/kugua-compiler.js"></script>
<script src="editor/kugua-loader.js"></script>
<script type="text/kugua">说（“你好，网页！”）。</script>
<script type="text/kugua" src="app.ks"></script>
```

离线静态页面可用单文件版（编译器 + 运行时 + 加载器合一，`file://` 下也可运行）：

```html
<script src="editor/kugua-loader.full.js"></script>
<script type="text/kugua">说（“你好，离线页面！”）。</script>
```

重新生成浏览器构建：`node build-browser.js`（编译器）、`node build-loader.js`（单文件版）。

## 构建插件（Vite / esbuild）

让 `.ks` 作为模块进入现代前端工程：

```js
// vite.config.js
const kugua = require('kuguascript/plugins/vite-plugin-kugua');
module.exports = { plugins: [kugua()] };
```

```js
import './app.ks';
```

用法详见 [plugins/README.md](plugins/README.md)。

## VS Code 扩展

`vscode-extension/` 提供 `.ks` 语法高亮 + 集成终端运行。安装现成打包（`kuguascript-vscode-0.2.0.vsix`）或源码调试，详见 [vscode-extension/README.md](vscode-extension/README.md)。

> 插件发布约定：每次发布前在 `package.json` 递增版本号，并在 `vscode-extension/CHANGELOG.md` 顶部新增更新说明，再运行 `build.ps1` 打包。完整流程见插件 README 的"发布流程"一节。

## 目录结构

```text
KuguaScript/
├── cli.js                    # 命令行入口
├── server.js                 # 编辑器本地服务器（http://localhost:3002）
├── src/
│   ├── lexer.js              # 词法分析器
│   ├── parser.js             # 语法分析器
│   ├── codeGenerator.js      # 代码生成器
│   ├── compiler.js           # 编译器主入口
│   ├── errors.js             # 运行期错误中文翻译
│   ├── constants.js          # 关键字/令牌/标点定义
│   └── runtime/              # node.js / browser.js 运行时 + registry.js
├── editor/                   # 网页编辑器、语法指南、浏览器构建产物
├── plugins/                  # Vite / esbuild 插件
├── test/                     # 教程脚本（由浅入深）+ 网页示例
└── vscode-extension/         # VS Code 插件
```

## 开发扩展

- **新增关键字/语法**：在 `src/constants.js` 登记关键字，在 `src/parser.js` 注册语句解析，在 `src/codeGenerator.js` 添加生成规则。
- **新增内置函数**：在 `src/runtime/registry.js` 登记名称，在 `src/runtime/node.js` 和/或 `src/runtime/browser.js` 实现，然后重新生成浏览器构建。
- **重新生成浏览器构建**：`node build-browser.js && node build-loader.js`。
