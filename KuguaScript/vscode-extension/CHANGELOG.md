# 更新说明（CHANGELOG）

> **发布约定：每次发布前，先在 `package.json` 递增版本号，再在本文件顶部新增一条对应版本的更新说明，最后运行 `build.ps1` 打包。**

## 0.2.0（2026-08-07）

- 语法高亮全面更新，覆盖新增句式：把/设字句（`把 分 增加 1`）、`当…时`/`重复 直到…为止`/`每当…就`、`遍历 名单 中 的 每个 元素`、`先…再…然后…最后…` 流水句、`尝试…如果报错`、`引入/导出/等待`、条件后缀 `的话` 等
- "的"语缀单独灰显（`正确的`、`空的` 等词尾的"的"按标点着色）
- 中文数字索引（`第一项`、`第二十三项`）按数字高亮
- 内置编译器同步升级：支持异步 `等待`（await）、`尝试…如果报错` 错误处理、`引入/导出` 模块互操作、中文命名空间标准库（路径/网址/加密/文件/系统/文本/列表 等）
- 打包内容加入本更新说明文件

## 0.1.0（初始发布）

- `.ks` 文件语法高亮、`（）【】` 与 `“”` 自动配对
- 深色主题"苦瓜脚本（深色）"
- 在集成终端运行脚本 / 编译为 JavaScript 两个命令（F5 / Ctrl+F5）
